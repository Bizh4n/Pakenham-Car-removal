QUOTE FORM / SMS
All quote forms prepare a text message addressed to:
0455 048 756

Important: Web browsers do not allow a normal static website to silently send an SMS
from a visitor's phone. When the customer presses the quote button, their SMS app opens
with the quote details filled in, and they tap Send.

For fully automatic SMS delivery after form submission, a backend and SMS provider
such as Twilio or MessageMedia must be connected.

PUBLISH WITH GITHUB PAGES
1. Create/open your GitHub repository.
2. Upload ALL files and the assets folder from this package.
3. Go to Settings > Pages.
4. Choose Deploy from a branch.
5. Select main and /(root), then Save.

PUBLISH WITH NETLIFY
1. Log in to Netlify.
2. Add new site > Deploy manually.
3. Drag this website folder into Netlify.
